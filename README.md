# 模拟飞行呼号（ICAO）生成器

一个开箱即用的单文件网页工具，为飞行模拟玩家一键生成符合国内 / 国际航线规则的 ICAO 呼号（**航司 ICAO 三字码 + 航班号**）。

## 功能特性

- 国内航线生成 **4 位**航班号，国外航线生成 **3 位**航班号
- 内置 **39 家国内航司 + 44 家国外航司**的 ICAO 三字码数据
- 航线类型自动切换可用航司列表：国际航线额外提供国外航司
- 支持「不允许前导 0（推荐）」与「允许前导 0」两种航班号规则
- 一键复制；点击生成结果或历史记录即可复制
- 生成历史记录（最多 20 条），支持一键清空
- 自动保存设置与历史记录（localStorage），刷新页面不丢失
- 连续两次生成不会产生相同呼号
- 纯前端、零依赖、无网络请求，可完全离线使用

## 使用说明

| 操作 | 说明 |
| --- | --- |
| 生成呼号 | 点击「生成呼号」按钮或按 `Enter` |
| 复制结果 | 点击「复制结果」按钮，或直接点击页面上的呼号 |
| 复制历史 | 点击任意一条历史记录即可复制该呼号 |
| 清空历史 | 点击历史记录右上角的「清空」 |

## 如何修改航司数据

打开页面，脚本位于文件末尾的 `<script>` 标签内。修改顶部的两个数组即可增删航司：

```js
const DOMESTIC_AIRLINES = [
  { name: "中国国际航空 Air China", icao: "CCA" },
  // 增删或修改这里
];

const FOREIGN_AIRLINES = [
  { name: "国泰航空 Cathay Pacific", icao: "CPA" },
  // 增删或修改这里
];
```

格式说明：

- `name`：航司展示名（支持中英文）
- `icao`：航司 ICAO 三字码，需与正式代码一致

如需调整航线对应的航班号位数，可修改 `ROUTE_META`：

```js
const ROUTE_META = {
  domestic: { label: "国内航线", digits: 4 },
  international: { label: "国外航线", digits: 3 }
};
```
